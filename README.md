## 🚀 Featured Projects

### 💬 [ChatSphere — Real-Time Microservices Communication Platform](https://github.com/Krishnasingh9999/ChatSphere)
> A scalable, event-driven real-time communication platform built on a distributed microservices architecture.
- **Microservices & Event-Driven:** Decoupled User, Mail, and Chat services communicating asynchronously via **RabbitMQ** and **Socket.IO**.
- **Real-Time & Calls:** Instant messaging, read receipts, live typing indicators, and **P2P Voice/Video Calling** via **WebRTC** with Google STUN servers.
- **Security & Caching:** Passwordless OTP authentication via asynchronous worker queues, Redis rate-limiting, and PBKDF2-encrypted secret chat vaults.
- **DevOps:** Containerized with Docker Compose, Nginx reverse proxy, SSL, and deployed on **AWS EC2**.
- **Tech Stack:** `React 19` `TypeScript` `Node.js` `Express` `MongoDB` `Redis` `RabbitMQ` `Socket.IO` `WebRTC` `Docker` `AWS`
- **Links:** [🌐 Live Application](https://chatsphere-live.duckdns.org) &nbsp;|&nbsp; [💻 GitHub Repository](https://github.com/Krishnasingh9999/ChatSphere)
