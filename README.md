## 🚀 Featured Projects

### 💬 [ChatSphere — Real-Time Microservices Communication Platform](https://github.com/Krishnasingh9999/ChatSphere)
A scalable, event-driven real-time communication platform built on a distributed microservices architecture supporting low-latency instant messaging, status stories, and multimedia exchange.  
Features free peer-to-peer WebRTC voice/video calling with Google STUN servers, passwordless OTP authentication via asynchronous RabbitMQ worker queues, Redis rate-limiting, and PBKDF2-encrypted secret chat vaults.

- **Tech Stack:** `React 19` `TypeScript` `Node.js` `Express` `MongoDB` `Redis` `RabbitMQ` `Socket.IO` `WebRTC` `Docker` `AWS`
- **Links:** [🌐 Live Application](https://chatsphere-live.duckdns.org) &nbsp;|&nbsp; [💻 GitHub Repository](https://github.com/Krishnasingh9999/ChatSphere)

### 🎬 [SyncTube — Real-Time Collaborative WatchParty Platform](https://github.com/Krishnasingh9999/synctube-watchparty-platform)
A full-stack collaborative watch party platform enabling friends and communities across the globe to watch YouTube videos in real-time synchronization with integrated live chat and emoji reactions.  
Built with low-latency Socket.IO room events, dynamic host/viewer role management, SendGrid automated email invitations, and Redis-cached active session state.

- **Tech Stack:** `React` `Node.js` `Express` `MongoDB` `Redis` `Socket.IO` `SendGrid` `TailwindCSS`
- **Links:** [🌐 Live Demo](https://synctube-watchparty-platform-1.onrender.com/) &nbsp;|&nbsp; [💻 GitHub Repository](https://github.com/Krishnasingh9999/synctube-watchparty-platform)
