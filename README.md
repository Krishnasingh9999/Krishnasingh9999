## 🚀 Featured Projects

### 💬 [ChatSphere — Real-Time Microservices Communication Platform](https://github.com/Krishnasingh9999/ChatSphere)
> **ChatSphere** is a high-performance, event-driven real-time communication platform designed using a distributed microservices architecture. It delivers seamless, low-latency messaging, multimedia sharing, and zero-cost peer-to-peer audio/video calling.

- **Distributed Microservices:** Decoupled into **User Service** (auth & profiles), **Mail Service** (async worker), and **Chat Service** (real-time messaging) communicating via **RabbitMQ** message broker.
- **Real-Time Messaging & Status:** WebSocket communication using **Socket.IO** with delivery receipts (Sent, Delivered, Seen), live typing indicators, and 24-hour disappearing status stories.
- **P2P Audio & Video Calling:** Implemented high-definition peer-to-peer calling via **WebRTC** with Google public STUN servers, complete with picture-in-picture (PIP) mode and media toggles.
- **Security & Performance:** Passwordless email OTP authentication, Redis-backed rate limiting & OTP expiration, and private chat vaults secured with **PBKDF2 SHA-512** encryption.
- **DevOps & Cloud:** Containerized using **Docker Compose**, configured with **Nginx** reverse proxy & SSL, and deployed on **AWS EC2**.
- **Tech Stack:** `React 19` `TypeScript` `Node.js` `Express.js` `MongoDB` `Redis` `RabbitMQ` `Socket.IO` `WebRTC` `Docker` `AWS`
- **Links:** [🌐 Live Application](https://chatsphere-live.duckdns.org) &nbsp;|&nbsp; [💻 GitHub Repository](https://github.com/Krishnasingh9999/ChatSphere)

### 🎬 [SyncTube — Real-Time Collaborative WatchParty Platform](https://github.com/Krishnasingh9999/synctube-watchparty-platform)
> **SyncTube** is a collaborative multimedia platform that allows friends and communities across the globe to watch YouTube videos in perfect synchronization while interacting via live chat and real-time reactions.

- **Synchronized Playback:** Leverages **Socket.IO** and YouTube IFrame Player API to synchronize play, pause, buffering, and seek events across all connected clients in real-time.
- **Interactive Community Experience:** Integrated real-time room chat, live floating emoji reactions, dynamic room management, and role-based permissions (Host/Viewer).
- **Email Invites & Caching:** Automated room invitation links dispatched using **SendGrid SMTP**, with active room sessions and participant states cached in **Redis**.
- **Responsive Interface:** Modern, mobile-first design built with React and Tailwind CSS providing dark mode and distraction-free theater mode.
- **Tech Stack:** `React.js` `Node.js` `Express.js` `MongoDB` `Redis` `Socket.IO` `SendGrid` `TailwindCSS`
- **Links:** [🌐 Live Demo](https://synctube-watchparty-platform-1.onrender.com/) &nbsp;|&nbsp; [💻 GitHub Repository](https://github.com/Krishnasingh9999/synctube-watchparty-platform)
